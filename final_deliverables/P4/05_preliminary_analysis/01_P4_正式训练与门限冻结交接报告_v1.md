## 5. P4 验证阶段初步分析（供报告第 4、6、8 章直接引用）

1. **TQC 相比 SAC 的跨种子稳定性与验证期优势**：
   - 在 2021–2022 上证 50 大跌 `-27.67%` 的行情下，100k 步 SAC 与 TQC 均大幅跑赢上证 50 基准（累计超额约 `+13%`），但跑输低波动防御股贡献显著的同池 48 股等权基线（`+2.54%`）。
   - 对比 `T0` 与 `S0`，TQC 在验证集上的 3 种子平均 Sharpe 更高（`-0.1089` vs `-0.1493`），且**跨种子 Sharpe 标准差仅为 SAC 的约 40%（`0.0331` vs `0.0829`）**，体现了分位数分布学习与右尾截断对高噪声金融环境的稳定作用。
2. **训练步数增加导致的 Critic 优势尺度收缩（Scale Shift）与过度拒绝现象**：
   - 在 20,000 步 Pilot 模型上，熵系数 $\alpha$ 尚处退火中期，策略与零动作的 Critic 估值差 $\Delta(s, a)$ 幅度较大（TQC 中位数 `1.87`），当时 `delta_threshold = 1.4` 能有效抑制过度换手（成交从 `2,650` 笔降至 `1,551` 笔，验证收益提升 `+14.61%`）。
   - 当训练充分收敛至 100,000 步（99,000 次梯度更新）后，$\alpha$ 退火至 `~0.001`，无门限模型本身的换手已大幅收敛（`Seed 2024/2026` 成交仅 `74–109` 笔，`gross_turnover ≈ 1.0x`），同时 Critic 对单步调仓相对持有的边际优势估计 $\Delta(s, a)$ 显著收窄。此时沿用 20k Pilot 分位数标定的正阈值（如 `0.26`、`1.4`）会导致多数种子出现 **100% 整向量拒绝（全程空仓持现）**（仅在换手仍较高的 `TQC seed=42` 上，`delta_threshold = 2.1` 将亏损从 `-12.80%` 收窄至 `-5.78%`、Sharpe 升至 `-0.0125`）。
3. **验证选优规则 `null` 处理机制的关键防泄漏作用**：
   - 在验证期熊市中，全程空仓持现的收益率为 `0.0%`，表面高于任何持仓多头策略的负收益；若选优规则错误地将零波动导致的 `sharpe = null` 视为 `0.0`，则会错误选出“永不交易”的退化阈值。本项目预先冻结的 `p4_val_sharpe_v1` 规则严格剔除含 `null` Sharpe 的退化候选，自动收敛并冻结在尺度无关的自然符号边界 `delta_threshold = 0.0`（即仅要求 Critic 认为动作优于零动作）。
4. **补充探索性消融与参数优化分析（不影响主实验冻结值）**：
   - 在维持上述主实验 `S2 / T2` 冻结参数 `delta_threshold = 0.0` 不变且严格隔离测试集的前提下，P4 进一步完成了“首日现金吸引子（Day-0 Cash Attractor）”机理诊断、100k TQC 细粒度门限扫描（`Δ > 0.22` 下 3 种子平均验证亏损减半至 `-7.17%`、最大回撤降至 `-29.75%`、Sharpe 升至 `-0.0722`）及 TQC 上尾截断与固定熵正则超参消融（`C0–C4`），详见 [P4 补充诊断与参数优化消融分析](../modules/module_p4_ablation_optimization.md)。
